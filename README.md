# OIBSIP - Oasis Infobyte Data Science Internship

This repository contains the projects completed during the Oasis Infobyte Data Science Internship.

## Projects

### 1. Unemployment Analysis with Python
- Data cleaning and analysis of unemployment data
- Visualization using Matplotlib and Seaborn
- State-wise unemployment trend analysis

### 2. Email Spam Detection with Machine Learning
- Spam email classification using Machine Learning
- Text preprocessing and prediction system
- Naive Bayes classification model

### 3. Sales Prediction Using Python
- Sales prediction using advertising data
- Linear Regression model implementation
- Data visualization and prediction analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
