# Email Spam Detection with Machine Learning

## About
This project uses Machine Learning to classify emails as spam or ham (non-spam). The model is trained using Python and Scikit-learn.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Features
- Email spam classification
- Text preprocessing
- Machine learning model training
- Spam prediction system
- Data visualization

## Machine Learning Algorithm
- Multinomial Naive Bayes

## Dataset
The dataset contains labeled email messages categorized as spam or ham.

## Conclusion
This project successfully detects spam emails using Machine Learning techniques and achieves high prediction accuracy.
